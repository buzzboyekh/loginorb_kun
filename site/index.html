Lock-in Orb

桌面常駐的解壓小球，也是陪你專注的燈。

上面那顆是活的：點一下換色，按住蓄力，連點會破。

安裝（macOS） GitHub

兩種心情，一顆球

想發洩的時候

短按換色、按住蓄力、連點或用力甩到極限就像泡泡一樣破掉再長回來。MacBook 觸控板會跟著分段震動。

想專注的時候

選單列按一下「開始專注 25 分鐘」。小球呼吸放慢、不再換色，外圈的點陣環顯示進度；切去 LINE 它會變灰提醒你；時間到自己爆開慶祝。

顏色來自《光與壑》

莫內四季 × 四個時段，16 組色票，同色系調和，不會變成彩虹。

只在本機

聽聲音模式只算音量，不錄音不上傳；分心偵測只拿前景 App 的名稱。沒有帳號、沒有網路請求。

操作

短按小球換下一個顏色
按住蓄力，震動分四段，約 5 秒會爆
連點／用力甩泡泡越來越鼓，到極限破掉，1 秒後長出新的
拖曳移動位置（會記住）
右鍵／選單列圓圈專注、換色、色票、大小、透明度、設定
⌥⌘O顯示／隱藏小球
⌥⌘L開始／結束專注

安裝

目前是開源專案，還沒有簽名過的安裝檔。需要 macOS 與 Node.js 18 以上。

git clone https://github.com/graceclara/lockinorb.git
cd lockinorb
npm install      # 會下載 Electron，約 100MB
npm start
  1. 第一次打開會跳出設定精靈：試一下震動、決定要不要給麥克風、選專注長度和顏色。
  2. 小球出現在右下角，選單列多一個圓圈。Dock 不會有圖示。
  3. 想做成 App：npm run pack（Apple Silicon）或 npm run pack:intel，成品在 dist/，拖進「應用程式」。
  4. 想開機自動出現：設定 → 系統 → 登入時自動啟動。

分心偵測第一次啟動時 macOS 會問「Lock-in Orb 想控制 System Events」，這是用來讀前景 App 名稱的；不允許也能正常用。
