# Lock-in Orb

桌面常駐的解壓小球。像 Siri 球一樣會流動，色票取自《光與壑》（莫內 4 季 × 4 時段），球裡面疊著 flow field 筆觸。

## 啟動

需要 Node.js 18 以上。

```bash
cd lockin-orb
npm install      # 會下載 Electron，約 100MB
npm start
```

小球會出現在螢幕右下角，選單列多一個圓圈圖示，Dock 不會有圖示。

## 操作

| 動作 | 效果 |
| --- | --- |
| 短按小球 | 換下一個顏色（有水波） |
| 按住小球 | 蓄力：震動分四段（輕慢 → 輕快 → 中 → 中快），每升一段有一下中等的連打；按滿約 5 秒會爆破（預兆 → 屏息 → 最重的爆 → 衝擊波 → 碎片落地）。中途放開會 Q 彈晃動 |
| 連點小球 | 泡泡越來越鼓、邊緣出現虹彩，越接近極限累積越慢，約 13 下會像泡泡一樣破掉，1 秒後長出新的淡色泡泡（停手 0.8 秒張力會慢慢鬆掉） |
| 拖著小球用力來回甩 | 也會累積張力，甩夠了就爆；慢慢拖動不會算 |
| 拖曳小球 | 移動位置（會記住） |
| 周圍有人說話 | 小球跟著音量變亮、變大、輕輕顫動，不同音高推動不同色塊，每個音節開頭從邊緣送出一圈聲波（選單可關、可調靈敏度） |
| 右鍵小球 / 點選單列圖示 | 換色、自動變色開關、16 組色票、大小、透明度、結束 |
| `⌥⌘O` | 顯示／隱藏小球 |

小球以外的透明區域不會擋住滑鼠，點得到下面的視窗。

## 打包成 App

```bash
npm run pack          # Apple Silicon (M 系列)
npm run pack:intel    # Intel Mac
```

成果在 `dist/Lock-in Orb-darwin-*/Lock-in Orb.app`，拖進「應用程式」即可。
想開機自動出現：系統設定 → 一般 → 登入項目 → 加入 Lock-in Orb。

## 想調整的地方

- 自動變色間隔：`main.js` 的 `AUTO_INTERVAL_MS`（預設 12 秒）
- 色票：`renderer/palettes.js`
- 球的大小選項：`main.js` 的 `SIZES`
- 流動速度、筆觸數量、擠壓手感：`renderer/orb.js`（`N_PARTICLES`、`tw += dt * ...`、彈簧參數）

不裝 Electron 也能預覽畫面：直接用瀏覽器開 `renderer/index.html`（網址後面加 `?p=0` 到 `?p=15` 可指定色票）。

## 跟著聲音波動（聽課模式）

用麥克風在本機即時算音量和頻段，**不錄音、不存檔、不上傳**。開著的時候 macOS 選單列會出現橘色的麥克風小點。

- 背景噪音（冷氣、風扇）會自動當作基準：取最近 3 秒音量的第 10 百分位，所以安靜時小球不會亂動，有人說話才會起伏。
- 選單列圖示 →「跟著聲音波動」開關；「聲音靈敏度」低／中／高。
- 第一次開會問麥克風權限。用 `npm start` 從終端機啟動時，macOS 可能會用「終端機」的名義詢問。
- 如果按了不允許：選單會變成「麥克風權限被關掉了，點這裡打開」，點下去會直接開到系統設定的麥克風頁面。

## 觸控板震動

有兩種做法，會自動選能用的那個：

1. **分段強度（優先）**：用 Python（conda 也可以）呼叫 macOS 私有框架 MultitouchSupport 的 `MTActuator`，和開源專案 HapticKey 同一招。可以用弱（ID 3）、中（ID 4）、強（ID 6）三種強度，手指沒碰著觸控板也會震。對照表在 `lib/haptics.js` 的 `LEVELS`。
2. **系統內建（備援）**：透過 `osascript` 呼叫 `NSHapticFeedbackManager`，只有輕／重兩種，手指要碰著觸控板。

只有 MacBook 內建的 Force Touch 觸控板會震，外接滑鼠不會。

測試：在資料夾裡執行 `npm run test-haptic`，會依序播放各段強度，最後還會試其他 ID（1、2、5、15、16）。如果覺得哪個比 6 更重，可以改 `lib/haptics.js` 的 `LEVELS.mt`。
用 `npm start` 啟動時，終端機會印出 `[haptic] 分段震動已啟用` 或改用備援的原因。
不想要震動：選單列圖示 → 取消勾選「觸控板震動」。

## 疑難排解

- 小球不見了：選單列圖示 → 顯示小球 → 移回右下角。
- 首次打包後無法開啟：在 App 上按右鍵 → 打開。
